📘 Bienvenido al Proyecto

Sistema de Registro y Análisis de Incendios

Este proyecto busca ayudar a los cuerpos de bomberos y autoridades locales a prevenir y responder incendios urbanos mediante el análisis de datos históricos, condiciones climáticas, zonas de riesgo y causas comunes.

A través de una plataforma web centralizada, se podrá registrar, visualizar y analizar incidentes pasados para tomar decisiones más informadas, optimizar recursos y salvar vidas.

🚒 Objetivo: Transformar datos dispersos en conocimiento accionable para la seguridad pública.
